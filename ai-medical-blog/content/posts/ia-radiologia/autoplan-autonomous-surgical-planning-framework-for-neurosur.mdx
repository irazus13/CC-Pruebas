## Resumen

**BACKGROUND:** Accurate path planning for minimally invasive neurosurgery is necessary to navigate complex anatomy that contains critical structures, such as blood vessels, ventricles and white-matter tracts. Planning with nonholonomic kinematics is difficult, and typical planners fail to generate kinematically feasible paths. **METHODS:** AutoPlan is a deep reinforcement learning (DRL) framework that generates a needle trajectory on a magnetic resonance imaging (MRI) patient dataset. AutoPlan implements kinematic control strategies, variable curvature with fixed insertion (VCFI) and variable insertion with fixed curvature (VIFC), with random and selective start-point initialisation. Path planning was performed on 55 volumes using PPO, SAC, DDPG and RRT. **RESULTS:** PPO (VIFC, selective start): 90.9% success, path length 45.96 &#xb1; 14.76&#xa0;mm, computation time 0.02 &#xb1; 0.02&#xa0;s. RRT: 65.5% success, path length 102.07 &#xb1; 126.15&#xa0;mm, computation time 9.72 &#xb1; 20.29&#xa0;s. **CONCLUSIONS:** AutoPlan provides consistent planning while avoiding critical structures, resulting in fast, kinematically safe trajectories.
