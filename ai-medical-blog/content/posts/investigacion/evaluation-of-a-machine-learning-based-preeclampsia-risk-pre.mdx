## Resumen

The purpose of this study was to develop and evaluate a parsimonious preeclampsia prediction model using routinely available clinical and demographic data from electronic health records (EHRs). We analyzed data obtained from a large tertiary healthcare system comprising 12&#xa0;787 deliveries, including 1444 women with preeclampsia and 11&#xa0;343 without. Predictive features included demographics, parity, vitals, diagnoses, encounters, labs, and social history. The dataset was partitioned into training (70%) and test (30%) sets. We evaluated multiple machine learning algorithms, including logistic regression, random forest, k-nearest neighbors, support vector machine, and extreme gradient boosting (XGBoost). Test set performance was assessed using accuracy, precision, recall, F1-score, and area under the receiver operating characteristic curve (AUC). To further examine different data source contribution, we evaluated the performance of the best-performing model using features from combinations of individual domains. XGBoost performed best (accuracy = 0.715, precision = 0.231, recall = 0.641, F1 = 0.340, AUC = 0.753.). Reduced feature sets showed comparable performance. Top combinations included: (a) parity, vital signs, and laboratories (AUC = 0.740; recall = 0.657); (b) diagnosis codes, vital signs, and laboratories (AUC = 0.740; recall = 0.678); and (c) diagnosis codes, vital signs, demographics, and laboratories (AUC = 0.738; recall = 0.633). Routinely collected EHR data can support prediction of preeclampsia with moderate discrimination and high recall. Comparable performance of reduced feature sets supports scalability and implementation in diverse settings. External validation and prospective studies are needed to support integration into clinical decision support systems, particularly in settings with incomplete prenatal data.
