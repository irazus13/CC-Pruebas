## Resumen

Postoperative care following dental extractions requires clear and continuous guidance; however, patient adherence to postoperative instructions remains suboptimal, and access to timely professional support may be limited. This study aimed to develop and evaluate PostOPbot, an artificial intelligence (AI)-based virtual assistant designed to provide standardized postoperative guidance through natural language processing. The system was implemented in Python with a web-based interface and integrated with the ChatGPT-4o application programming interface through a conversational endpoint. Postoperative recommendations were identified through a structured PubMed search and incorporated into a static prompt that defined the system's operational rules, restricted its scope to postoperative counseling, and guided the interpretation of user input. The rule set was embedded into the code so that each user query was combined with predefined instructions before being processed by the language model. The chatbot was evaluated using three simulated postoperative scenarios representing different time intervals after tooth extraction. For each scenario, the system was expected to provide a predefined set of recommendations, and its performance was assessed by determining whether each item was delivered spontaneously or only after explicit prompting. PostOPbot provided most expected recommendations with few omissions, and missing recommendations were consistently generated upon direct request. Although large language model-based systems have inherent limitations, the findings suggest that PostOPbot may serve as a complementary AI tool to reinforce postoperative guidance without replacing professional evaluation.
